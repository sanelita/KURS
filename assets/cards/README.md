# Galerija karata (placeholder fajlovi)

Možeš ih **zameniti svojim ilustracijama** (PNG/JPG/SVG) bez menjanja naziva fajlova.

```

  major/   -> 22 Velike Arkane (major-XX-naziv.svg)
  minor/   -> 56 Male Arkane (po bojama)
```

## Kako zameniti slike
1. Sačuvaj svoju sliku pod istim nazivom (npr. `major-00-luda.svg`).
2. GitHub/Markdown će automatski prikazati novu sliku.

Ako želiš da koristiš druge nazive fajlova, samo promeni linkove u README-u.
